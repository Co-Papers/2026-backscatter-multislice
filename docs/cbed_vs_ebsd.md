# CBED 与 EBSD 的原理区别，及 Kikuchi 线 / HOLZ 线概念辨析

> 领域知识笔记 · 电子显微学 · 更新 2026-08-30

## 一句话区分
- **CBED（会聚束电子衍射，Convergent Beam Electron Diffraction）**：电子束**穿过**薄样品，探测器在样品**下方**，收**透射/前向**衍射盘。TEM 里做。
- **EBSD（电子背散射衍射，Electron Backscatter Diffraction）**：电子束打在**厚块体**表面，探测器在**侧面**，收从表面**背散射**出来的 Kikuchi 花样。SEM 里做。

两者都是电子衍射（均满足 Bragg 定律），差别在**几何（透射 vs 背散射）**、**制样（薄 vs 块体）**、**相干性**与**提取的信息**。

## 对比表

| 维度 | CBED (TEM) | EBSD (SEM) |
|---|---|---|
| 显微设备 | TEM / STEM | SEM（或 FIB-SEM） |
| 几何/散射方向 | **透射**（束穿过样品，探测器在下方的后焦面） | **背散射**（束打表面，探测器侧向） |
| 制样 | 必须**薄**（电子可穿透，≲100 nm 薄膜/减薄片） | **块体**、抛光表面，无薄片要求 |
| 入射束 | 会聚束（convergent，会聚角几 mrad~数十 mrad） | 聚焦小探针（nm 级，常光栅扫描） |
| 电子能量 | 80–300 keV（低能 TEM 用 20–80 kV） | 5–30 keV |
| 图案形态 | **衍射盘**（每个倒格点成圆盘；盘内有 HOLZ 线、厚度条纹） | **Kikuchi 带**（亮暗平行带相交于晶带轴） |
| 物理过程 | **相干动力衍射**：透射波在薄晶内多次散射，盘强度含位相/厚度/对称信息 | 电子先**非相干**散射生成"内部源"，再对该源做 **Bragg 衍射**，统计叠加成带 |
| 主要提取信息 | 晶体对称性/点群/空间群、晶格常数、样品厚度、应变、低能下背散射修正 | **取向**（orientation mapping）、相鉴定、晶粒尺寸、织构、应变 |
| 采样深度 | 贯穿整个薄层厚度 | 近表面 ~10–100 nm（表面灵敏） |
| 典型应用 | 晶体学/缺陷/结构精修、低能成像 | 取向成像、织构分析、EBSD 图谱 |

## 一张 CBED 图里其实有三类特征

| 特征 | 物理来源 | 是否 CBED 主信号 |
|---|---|---|
| **衍射盘**（disc） | 会聚束入射 → 相干 Bragg 衍射，每个倒格点成圆盘 | ✅ 主 |
| **盘内 HOLZ 线**（Higher-Order Laue Zone 线） | 三维动力衍射：高阶劳厄带反射在盘内满足 Bragg 条件的锐利细线 | ✅ 主（定晶格常数/电压/厚度） |
| **菊池线/带**（Kikuchi lines/bands） | 非相干散射电子作"内部源" → 再被晶格 Bragg 衍射 | ⚠️ 次要/背景 |

## 为什么 CBED 的重心不在菊池线
CBED 追求的是**相干动力学散射**信息：盘内强度分布、厚度条纹、对称性、HOLZ 线。菊池线来自**非相干**散射，通常只作为叠加在盘之间的**背景带**。因此：

- 定量分析 CBED → 看**盘**与**盘内 HOLZ 线**（对样品厚度、加速电压、晶格常数极敏感）。
- 菊池线 → 多为**辅助**：用于**精确对中晶带轴**（把菊池带中心对准），或作对称性/取向的粗略参考。

### 与 EBSD 对齐
- **EBSD**：整幅图就是菊池带（亮暗带相交于晶带轴），菊池带是**唯一主信号**，用于取向成像 → EBSD "非常关心" 菊池线。
- **CBED**：盘是主、HOLZ 是精、菊池线是**背景/辅助**。薄样品时盘结构清晰、菊池线弱；厚样品时菊池线增强，可能弱化盘结构。

## 易混淆点：HOLZ 线 ≠ 菊池线
- **菊池线**：来自**非相干**散射源 → 宽的带/线，跨越多盘。
- **HOLZ 线**：来自**相干动力**衍射 → 很锐，只在盘内（尤其中央 000 盘），对晶格常数/电压的细微变化极为敏感。

二者在 CBED 里常被误混，但物理来源与用途不同。

## 与本项目的关联（为什么这里研究背散射）
项目在做 **5 keV 低能 TEM 的透射 CBED**（SrTiO₃，厚约 195 Å），并引入**背散射修正**（该修正项为 **abTEM** 的 `RealSpaceMultislice(expansion_scope="full")` 自带机制：低能时，即使 CBED 是"透射几何"，样品内部仍会有不可忽略的**背散射分量**修正前向波；Wacker 2015 对低能背散射有系统分析，可作参考）。而 **EBSD 恰恰把这些背散射电子当作有用信号**。

- CBED：把背散射当**修正项**（透射为主）。
- EBSD：把背散射当**主信号**（背散射为主）。

一句话：**CBED 看透射里的结构信息，EBSD 看背散射里的取向信息；同一套 Bragg 物理，不同的几何、制样与信噪比取舍。**
